Recent Projects

Ultrasonic Sensor with VGA Display

SystemVerilog | FPGA | Oscilloscope

Engineered a custom PWM controller for a servo motor and configured an HC-SR04 sensor to scan surroundings. Designed a VGA display to visualize real-time scanning data.

FPGA-Based Binary Counter

Assembly | DE10-Lite | Digital Logic

Developed a 4-bit binary counter on a DE10-Lite FPGA board using Assembly. Implemented real-time incrementing and resetting via onboard switches.

Touch-Sensitive Electronic Dice

PCB Design | Soldering | Circuit Diagnostics

Soldered a compact circuit simulating a random dice roll on a 3x3 LED array using SMT and THT techniques. Engineered a custom touchpad activation mechanism.
